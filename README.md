# Mostrador

Facturación y stock para pymes: clientes, productos con stock y facturas con IVA. Hecho con Next.js y Firebase.

## Puesta en marcha

1. Copia `.env.example` a `.env.local` y rellénalo con la configuración web de tu proyecto de Firebase.
2. `npm install`
3. `npm run dev` y abre http://localhost:3000

## Comandos

- `npm run dev` · desarrollo
- `npm test` · tests unitarios (Vitest)
- `npm run check` · tipos + lint + tests + build
